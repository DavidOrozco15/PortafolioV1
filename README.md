# PortafolioV1

Portafolio personal de David Orozco — Full-Stack Developer.

## Tecnologías

- React 18
- Vite
- CSS puro

## Estructura

```
src/
├── components/    # Componentes de cada sección
│   ├── IntroAnimation
│   ├── Background
│   ├── Navbar
│   ├── Hero
│   ├── About
│   ├── MissionVision
│   ├── Services
│   ├── Projects
│   ├── Certifications
│   └── Contact
├── hooks/         # Custom hooks
├── styles/        # Estilos globales
└── img/           # Imágenes y certificados
```

## Secciones del portafolio

- Hero — presentación principal
- About — información personal
- Misión y Visión
- Servicios que ofrece
- Proyectos realizados
- Certificados
- Formulario de contacto

## Instalación

```bash
npm install
```

## Desarrollo

```bash
npm run dev
```

## Build

```bash
npm run build
```
